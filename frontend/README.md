# SmartAg Frontend

React + TypeScript + Vite web app for the SmartAg Sensor System dashboard. Also packaged as an Android app via Capacitor.

See the [root README](../README.md) for full setup and project documentation.

## Quick Start

```bash
npm install
npm run dev
```

## Android

```bash
npm run build
npx cap sync
npx cap open android
```
